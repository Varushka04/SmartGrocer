# SmartGrocer by The Spirals

Placed third in KZN - GirlCode Hackathorn (October 2025)

Team Members: Varushka Dayal, Luyanda Mhlongo, Nosipho Ngwenya

**SmartGrocer** is an app designed to help people with budgeting for groceries by recommending small local businesses close to the user, while comparing prices of the cheapest stores to shop at.

Although the codebase was developed collaboratively during the hackathorn and is not pubicly available, this repository showcases the project concept, demo and presentation.
